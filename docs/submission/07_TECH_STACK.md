# Technology Stack

- **Backend:** Node.js, Express, TypeScript, Zod Schema Validation
- **Frontend:** React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons
- **AI Compiler:** Google Gemini (`gemini-3.6-flash`) with Deterministic Rule Engine Fallback
- **Database:** Dual-Engine Architecture (MongoDB Mongoose + In-Memory Store)
- **Payment Processing:** Razorpay Node.js SDK (Test Mode) + Simulated Sandbox Bridge
- **Security & Cryptography:** Timing-safe HMAC SHA-256 signatures, proposal snapshot digests, 10m TTL tokens
- **Testing:** 49 automated unit and integration tests covering policy logic, approval lifecycles, and payment verification
